# Validation Agent 검증 기준

> 관련 이슈: #91 (기준 확정) → #92 (로직 구현)

## 1. 자막 길이 제한

- **상수명**: `MAX_CAPTION_LENGTH`
- **값**: `60`
- **기준**: 씬(scene) 1개당 자막 전체 글자수
- **역할**: 하드 컷오프 안전장치. 실제 화면상 가독성(줄바꿈, 폰트 크기, 한 줄에 보이는 글자 수)은 이 값의 책임 범위가 아니며, FFmpeg Render Agent에서 처리한다.
- **비고**: 현재는 근거값으로 확정했으며, 실제 렌더링 결과를 확인한 뒤 재조정 가능성을 열어둔다.

## 2. 부적절 표현 필터링

- **포함 여부**: 포함
- **방식**: 키워드 기반 (LLM 기반 아님)
  - 이유: LLM 기반 필터링은 API 호출이 추가되어 파이프라인 지연시간/비용이 늘어남. 키워드 매칭으로 최소한의 안전장치를 확보하는 것으로 충분하다고 판단.
- **범위**: 욕설 위주의 최소 금칙어 세트로 시작, 필요시 확장
- **실제 리스트 구성 및 적용 로직**: #92에서 구현

## 3. 필수 필드 검증 (기존 구현 유지)

- `bgm_id` 존재 여부 (기존 로직 유지)

## 4. 검증 실패 시 처리 (기존 구현 유지, 변경 없음)

- `state["validation_passed"] = False`
- `state["validation_errors"]`에 실패 사유 기록
- `state["status"] = "FAILED"`, `state["error_message"]`에 사유 기록
- `route_after_validation`을 통해 Render 단계 진입 차단
