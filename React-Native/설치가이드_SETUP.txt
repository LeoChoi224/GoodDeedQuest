========================================================
 선행퀘스트 (GoodDeedQuest) - Expo 앱 실행 사전 설치 가이드
========================================================
프로젝트 위치: GoodDeedQuest/Ract-Native
기술 스택: Expo SDK 54 / React Native 0.81 / React 19
작성 기준: 2026-07-07


--------------------------------------------------------
[0] 한눈에 보기 (공통)
--------------------------------------------------------
반드시 설치해야 하는 것:
  1) Node.js  (LTS 20.x 이상 권장)  ← npm 포함됨
  2) 휴대폰에 "Expo Go" 앱  (App Store / Play Store)

선택(시뮬레이터/에뮬레이터로 돌리고 싶을 때):
  - iOS 시뮬레이터  : Xcode  (※ Mac에서만 가능)
  - Android 에뮬레이터 : Android Studio  (Windows / Mac 공통)

가장 쉬운 실행 방법 = 실제 폰 + Expo Go + QR 스캔
(시뮬레이터/에뮬레이터 없이 바로 됨. Wi-Fi만 같으면 OK)


========================================================
 A. 윈도우(Windows) 버전
========================================================

--------------------------------------------------------
[A-1] Node.js 설치
--------------------------------------------------------
방법 1) 설치 파일로 (가장 쉬움)
  - https://nodejs.org 접속 → "LTS" 버전 다운로드 → 설치
    (설치 중 "Add to PATH" 체크는 기본으로 되어 있음)

방법 2) 명령어로 (winget - 윈도우 10/11 기본 내장)
  winget install OpenJS.NodeJS.LTS

설치 확인 (PowerShell 또는 명령 프롬프트에서):
  node -v
  npm -v
  ※ node 버전이 v20 이상이면 정상

--------------------------------------------------------
[A-2] (선택) Git 설치 - 협업/버전관리 할 때
--------------------------------------------------------
  winget install Git.Git
  확인: git --version

--------------------------------------------------------
[A-3] (선택) Android 에뮬레이터 - 폰 없이 안드로이드로 볼 때
--------------------------------------------------------
  - https://developer.android.com/studio 에서 Android Studio 설치
  - Android Studio 실행 → More Actions → Virtual Device Manager
    → 가상 기기(예: Pixel) 생성 후 실행
  ※ 폰 + Expo Go로 볼 거면 이 단계는 필요 없음

--------------------------------------------------------
[A-4] 프로젝트 실행 (Windows)
--------------------------------------------------------
  1) 이 폴더로 이동
       cd 경로\GoodDeedQuest\Ract-Native

  2) 라이브러리 설치 (최초 1회, 시간 좀 걸림)
       npm install

  3) 개발 서버 실행
       npm start
       (= npx expo start 와 같음)

  4) 터미널에 뜬 QR 코드를
       - 폰에서 "Expo Go" 앱 → QR 스캔
       - 안드로이드 에뮬레이터로 보려면 터미널에서  a  키
       - 웹 브라우저로 보려면 터미널에서            w  키

  ※ QR로 연결이 안 되면(회사/학교 와이파이 등):
       npx expo start --tunnel


========================================================
 B. 맥(macOS) 버전
========================================================

--------------------------------------------------------
[B-1] Homebrew 설치 (맥 패키지 관리자, 없으면)
--------------------------------------------------------
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  확인: brew --version

--------------------------------------------------------
[B-2] Node.js 설치
--------------------------------------------------------
방법 1) Homebrew로
  brew install node

방법 2) 설치 파일로
  - https://nodejs.org 접속 → "LTS" 다운로드 → 설치

설치 확인:
  node -v
  npm -v
  ※ node 버전이 v20 이상이면 정상

--------------------------------------------------------
[B-3] (권장) Watchman 설치 - 파일 변경 감지 안정화
--------------------------------------------------------
  brew install watchman

--------------------------------------------------------
[B-4] (선택) iOS 시뮬레이터 - 아이폰 시뮬레이터로 볼 때  ※ Mac 전용
--------------------------------------------------------
  1) App Store에서 "Xcode" 설치 (용량 큼, 시간 걸림)
  2) 시뮬레이터용 명령줄 도구:
       xcode-select --install
  3) Xcode 한 번 실행해서 라이선스 동의 + 컴포넌트 설치

--------------------------------------------------------
[B-5] (선택) Android 에뮬레이터 - 안드로이드로 볼 때
--------------------------------------------------------
  - https://developer.android.com/studio 에서 Android Studio 설치
  - Virtual Device Manager에서 가상 기기 생성
  ※ 폰 + Expo Go로 볼 거면 필요 없음

--------------------------------------------------------
[B-6] 프로젝트 실행 (macOS)
--------------------------------------------------------
  1) 이 폴더로 이동
       cd ~/Desktop/KDT2604/GoodDeedQuest/Ract-Native

  2) 라이브러리 설치 (최초 1회)
       npm install

  3) 개발 서버 실행
       npm start
       (= npx expo start 와 같음)

  4) 실행 방법 선택
       - 폰에서 "Expo Go":  iOS는 기본 카메라로 QR 스캔 / 안드로이드는 Expo Go 앱에서 스캔
       - iOS 시뮬레이터:     터미널에서  i  키
       - 안드로이드 에뮬레이터: 터미널에서  a  키
       - 웹 브라우저:         터미널에서  w  키

  ※ QR 연결이 안 되면:
       npx expo start --tunnel


========================================================
 C. package.json에 등록된 실행 명령 (Windows/Mac 공통)
========================================================
  npm start          개발 서버 실행 (QR → Expo Go)   [= expo start]
  npm run android    안드로이드 에뮬레이터/기기로 바로 실행
  npm run ios        iOS 시뮬레이터로 바로 실행 (Mac 전용)
  npm run web        웹 브라우저로 실행

개발 서버 실행 중 단축키:
  i = iOS 시뮬레이터   a = 안드로이드   w = 웹
  r = 새로고침(리로드)  m = 메뉴         c = QR 다시 보기   q = 종료


========================================================
 D. 자주 나오는 문제 해결
========================================================
- "npm : 명령을 찾을 수 없음"  → Node.js 재설치 후 터미널 완전히 껐다 켜기
- 폰이 QR 스캔해도 연결 안 됨    → 폰과 컴퓨터가 같은 Wi-Fi인지 확인
                                  → 안 되면  npx expo start --tunnel
- 설치가 꼬였을 때(에러 반복)    → node_modules 폴더 삭제 후  npm install 다시
                                  → 그래도 안 되면  npx expo start -c  (캐시 초기화)
- 버전 호환성 자동 점검/수정      → npx expo install --check
