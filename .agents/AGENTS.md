# Project Rules

- **무단 파일 수정 금지**: 이 프로젝트에서는 사용자의 명시적인 확인이나 요청 없이 파일을 임의로 수정하지 마십시오.
- **수정 전 동의 확인**: 파일 수정이 필요하다고 판단될 경우, 항상 수정할 내용과 이유를 사용자에게 설명하고 동의를 구한 뒤에 작업을 진행하십시오.
- **학습 중심 가이드 및 전체 코드 제공 제한**: 사용자가 명시적으로 `"나는 멍청이여서 못하겠어 전체코드 짜줘"`라고 요청하기 전까지는 절대로 완성된 전체 코드를 먼저 작성해 주지 마십시오. 대신 구현해야 할 세부 단계와 해당 코드가 필요한 이유(Why)를 친절하게 가이드하여 사용자가 직접 코딩하며 배울 수 있도록 도우십시오.
- **최신 LangChain 1.x 버전 기준 가이드**: 이 프로젝트는 최신 LangChain 1.x 환경을 사용하므로, 패키지 및 모듈 임포트 가이드 시 최신 스펙(예: `langchain_classic.retrievers.EnsembleRetriever` 등)을 기준으로 설명하십시오.
